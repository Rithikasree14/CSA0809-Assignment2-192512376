# CSA08 – Assignment 2
## Control Flow, Strings and Functions

### About

This repository contains the Python programs I worked on as part of my CSA08 Assignment 2.

The assignment helped me understand different Python concepts through practical programs. I worked on conditional statements, loops, string operations, functions, recursion and basic algorithm optimization.

### Programs Included

**Q1 – Decisions with Many Boundaries**

Implemented electricity subsidy eligibility using separate `if` statements and `if-elif-else` statements.

**Q2 – Loops that Count Attempts**

Created an OTP verification program using `while` and `for` loops. It also demonstrates `break`, `continue`, `pass` and loop `else`.

**Q3 – Vehicle Registration Number Validator**

Developed a program to check whether vehicle registration numbers follow the given format without using regular expressions.

**Q4 – Building Long Text: + or join()?**

Compared different ways of building strings using the `+` operator, `join()` and F-strings. Also checked their execution times for different input sizes.

**Q5 – Functions, Parameters and Scope**

Worked with functions, default arguments, mutable default values, global variables and nonlocal variables.

**Q6 – Recursion and Its Limits**

Implemented the staircase problem using naive recursion, memoisation and an iterative approach. Compared the results and function calls.

**Q7 – Diagnose, Redesign and Validate**

Improved the staircase problem by replacing recursive calculations with iterative dynamic programming and checked whether both approaches produced the same results.
